# AI Research Engine

A modular Python research engine that discovers relevant web pages and YouTube videos for a given topic. It collects source metadata, publication dates, URLs, and available YouTube transcripts to support automated research and AI-powered content generation.

## Features

**Web Research**: Discover relevant web sources using DuckDuckGo search and extract useful page content and metadata.

**YouTube Research**: Discover relevant YouTube videos and collect available transcripts, video URLs, titles, and publication details.

**RAG Pipeline**: Process collected research documents into chunks, generate embeddings using Ollama, and store them in ChromaDB for semantic search.
